# تفعيل الشات العام

الواجهة موجودة في زر 💬 العائم وفي صفحة «المزيد». الشات مستقل عن بيانات الفلوس والنسخ الاحتياطية. الدخول بحساب Google؛ حساب Firebase Anonymous ممنوع من القراءة والكتابة بالقواعد.

## نشر قواعد قاعدة البيانات

1. افتح https://console.firebase.google.com/project/bhxx-2a3be/database/bhxx-2a3be-default-rtdb/rules
2. احتفظ بنسخة من القواعد المنشورة، وقارنها بملف `dev/firebase-rules.json` قبل النشر للحفاظ على أي مسارات أضيفت خارج المشروع.
3. انشر محتوى الملف؛ لا تفتح القراءة والكتابة على مستوى الجذر.

بديل باستخدام Firebase CLI بحساب مسؤول المشروع:

```powershell
npx firebase-tools login
npx firebase-tools deploy --only database --project bhxx-2a3be
```

تحديث GitHub وحده لا ينشر قواعد Firebase. رسالة «قد تحتاج قواعد الشات للتفعيل» تعني أن الخدمة رفضت الطلب؛ يمكن أن تعني أيضًا أن العضو محظور. الخروج من صفحة الشات والرجوع لها يعيد محاولة الاشتراك.

## الإشراف

- الرسائل: `publicChat/messages/{messageId}`.
- البلاغات الخاصة بالمشرف: `publicChat/reports/{messageId}/{reporterUid}`. كل عضو يستطيع تقديم بلاغ واحد لكل رسالة. يمكن مراجعة الرسالة بمعرّفها؛ البلاغ لا يحتفظ بنسخة من رسالة تم حذفها.
- لحظر عضو، أضف `chatBans/{uid}: true` من Firebase Console. احذف القيمة لإلغاء الحظر.
- المشرف يستطيع حذف الرسائل من Console. لإظهار زر حذف كل الرسائل داخل الموقع، امنحه custom claim باسم `chatAdmin: true` عبر Firebase Admin SDK في بيئة موثوقة، مع الحفاظ على أي claims موجودة. يجب تحديث جلسة تسجيل دخوله بعد ذلك.
- لا توجد لوحة بلاغات داخل الموقع في هذا الإصدار؛ مراجعتها من Console.

## النطاق والتحقق

آخر 100 رسالة بترتيب وقت الخادم، نص حتى 1000 حرف، إعجاب بالقلب، حذف المرسل أو المشرف، وبلاغات. العرض يستخدم textContent، ولا ينفذ HTML أو روابط من الرسائل. لا ننشر البريد الإلكتروني أو بيانات الحسابات المالية.

الإرسال متوقف عند انقطاع الاتصال، ولا يُعرض نجاحه إلا بعد تأكيد Firebase. فاصل الثلاث ثواني بين الرسائل حماية في الواجهة فقط؛ مقاومة السبام من عملاء معدّلين تحتاج backend يفرض حد الإرسال. App Check ومراقبة استخدام Firebase مناسبان قبل توسيع الجمهور.

اختبارات التطبيق:

```powershell
node --test tests/*.test.cjs
```

اختبار قواعد Firebase الحقيقي على قاعدة demo محلية (Java 21 مطلوب):

```powershell
npx firebase-tools emulators:exec --only database --project demo-bony-chat "node --test tests/chat-rules.test.cjs"
```

اختبار القواعد يتخطى التشغيل العادي بدون متغير FIREBASE_DATABASE_EMULATOR_HOST. لا ينشئ بيانات اختبار في المشروع الحقيقي.

# 💰 BH — إدارة الفلوس والقبض

تطبيق ويب (PWA) لإدارة القبض والمصاريف لفرسان الدليفري — يشتغل على الموبايل والكمبيوتر،
وبيشتغل **أوفلاين** بعد أول زيارة، وبيتثبّت على الشاشة الرئيسية زي أي تطبيق.

🔗 **الرابط:** https://tdrs10.github.io/-bh/

---

## ✨ المميزات

| الميزة | الوصف |
|---|---|
| 💵 **الرئيسية** | الرصيد الحالي + القبض + المصاريف + مخطط أسبوعي للمصروف اليومي |
| 📊 **الميزانية** | تقسيم تلقائي 50/30/20، مع تتبع المدخرات والمصاريف الأساسية والكماليات |
| 📅 **قفل اليوم** | تقفيل يومية الشغل وتسجيلها، مع منع التعديل بعد القفل |
| 🧠 **المحلل الذكي** | اكتب مصروفك بالعربي ("50 بنزين") وهو يفهمه ويسجله |
| 📈 **التقارير** | تقارير شهرية، متوسطات، ومقارنات |
| ☁️ **المزامنة** | Firebase — تسجيل دخول بـ Google ومزامنة بين كل أجهزتك |
| 🔔 **الإشعارات** | تنبيهات ذكية بالمصاريف والمدخرات |
| 📤 **المشاركة** | مشاركة التطبيق من خلال مشاركة النظام |

---

## 📱 تثبيت التطبيق على الموبايل (PWA)

1. افتح الرابط في **Chrome**.
2. من قائمة المتصفح (⋮) اختار **"تثبيت التطبيق"** أو **"إضافة إلى الشاشة الرئيسية"**.
3. هيظهر أيقونة BH على شاشتك ويفتح زي التطبيق بالظبط.

> كل تحديث بنرفعه على GitHub بيوصل تلقائيًا لكل الأجهزة — مش محتاج تحدّث حاجة بنفسك.

---

## ☁️ المزامنة السحابية

البيانات بتتخزن محليًا 100% على جهازك. لو فعّلت Firebase:

- تسجيل دخول بحساب Google → تفتح بياناتك من أي جهاز
- **دمج تلقائي** بدون ما تضيع بياناتك
- نسخ احتياطية تلقائية

الإعدادات موجودة في `firebase-config.js`.

## 🛠️ التطوير

```bash
# تشغيل سيرفر محلي
python -m http.server 8899
```

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة + المودالات |
| `app.js` | منطق التطبيق كله |
| `styles.css` | التصميم |
| `firebase-service.js` | خدمات المزامنة |
| `firebase-config.js` | إعدادات Firebase |
| `service-worker.js` | العمل أوفلاين + التحديثات |
| `manifest.json` | إعدادات تثبيت الـ PWA |

# 💰 BH — تطبيق إدارة الفلوس لفرسان الدليفري

تطبيق **PWA + Android app** لإدارة قبضك ومصاريفك، مع فصل **التحويش** عن الصرف، ومزامنة سحابية، وتحديات وشارات.

🔗 **الرابط:** https://mhmoudmohmed269-cmd.github.io/-bh/

---

## ✨ المميزات

| القسم | التفاصيل |
|---|---|
| 🏠 **الرئيسية** | الرصيد الكلي + المحجوز + المتاح، شريط رصيد دايماً في الهيدر، تنبيهات ذكية |
| 💵 **القبض** | تقسيم تلقائي 50/30/20، قبض قيد الانتظار، حاسبة وردية (أوردرات/ساعات/كم/ربح الساعة) |
| 🗺️ **خريطة الشغل** | خريطة حرارية 7 أيام × 6 فترات — بتوريك إمتى بتكسب أكتر |
| 💳 **المصاريف** | تحذير الخرجات الغالية، ميزانية أسبوعية، **شارك → BH** (parser عربي) |
| 🎯 **الأهداف** | أهداف + ديون + **مخطط سداد الديون** (أعلى/الأصغر أولاً + خط زمني) |
| 🏆 **التحديات** | 8 تحديات + 19 شارة مع احتفال |
| ☁️ **المزامنة** | Firebase + تسجيل دخول Google + صورة حسابك في الهيدر |
| 🔔 **التنبيهات** | رصيدك قارب يعمل / نسيت وردية / هدفك قارب يتحقق |

## 🔐 المزامنة السحابية

التطبيق بيشتغل 100% بدون نت (البيانات على الجهاز). لو فعّلت Firebase:
- بياناتك على السحابة → تفتحها من أي جهاز
- **دمج آمن** بدل الاستبدال (مفيش عملية بتضيع)
- 6 نسخ تلقائية + استرجاع فوري لو حصل خطأ

الإعداد موجود في `firebase-config.js` (اتبع الخطوات في الملف).

## 🛠️ التطوير

```bash
# سِرفر محلي
python -m http.server 8899

# بناء التطبيق الأصلي
npm install
npm run build:apk
```

| الملف | الوظيفة |
|---|---|
| `app.js` | منطق التطبيق كله |
| `index.html` | الهيكل + المودالات |
| `styles.css` | التصميم |
| `native-bridge.js` | طبقة Capacitor (no-op في المتصفح) |
| `firebase-service.js` | خدمة المزامنة |
| `scripts/make-android-icons.js` | توليد الأيقونات من اللوجو |
| `android/` | مشروع Android |

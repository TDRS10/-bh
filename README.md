# 💰 BH — إدارة الفلوس والقبض

تطبيق ويب (PWA) لإدارة القبض والمصاريف لفرسان الدليفري — يشتغل على الموبايل والكمبيوتر،
وبيشتغل **أوفلاين** بعد أول زيارة، وبيتثبّت على الشاشة الرئيسية زي أي تطبيق.

🔗 **الرابط:** https://tdrs10.github.io/-bh/

---

## ✨ المميزات

| الميزة | الوصف |
|---|---|
| 💵 **الرئيسية** | الرصيد الحالي + القبض + المصاريف + مخطط أسبوعي للمصروف اليومي |
| 📊 **الميزانية** | تقسيم تلقائي 50/30/20، مع تتبع المدخرات والمصاريف الأساسية والكماليات |
| 📅 **قفل اليوم** | تقفيل يومية الشغل وتسجيلها، مع منع التعديل بعد القفل |
| 🛵 **جدول الشغل** | "نزلت الشغل ولا لا؟" — تقويم شهري يحسب أيام النزول والراحة، ويوصل الشغل بالفلوس (قبض أيام الشغل + متوسط اليوم) |
| 🧠 **المحلل الذكي** | اكتب مصروفك بالعربي ("50 بنزين") وهو يفهمه ويسجله |
| 📈 **التقارير** | تقارير شهرية، متوسطات، ومقارنات |
| ☁️ **المزامنة** | Firebase — تسجيل دخول بـ Google ومزامنة بين كل أجهزتك |
| 🔔 **الإشعارات** | تنبيهات ذكية بالمصاريف والمدخرات |
| 📤 **المشاركة** | مشاركة التطبيق من خلال مشاركة النظام |

## 📱 تثبيت التطبيق على الموبايل (PWA)

1. افتح الرابط في **Chrome**.
2. من قائمة المتصفح (⋮) اختار **"تثبيت التطبيق"** أو **"إضافة إلى الشاشة الرئيسية"**.
3. هيظهر أيقونة BH على شاشتك ويفتح زي التطبيق بالظبط.

> كل تحديث بنرفعه على GitHub بيوصل تلقائيًا لكل الأجهزة — مش محتاج تحدّث حاجة بنفسك.

## ☁️ المزامنة السحابية

البيانات بتتخزن محليًا 100% على جهازك. لو فعّلت Firebase:

- تسجيل دخول بحساب Google → تفتح بياناتك من أي جهاز
- **دمج تلقائي** مع قيود عند تعديل نفس البيانات من أجهزة متعددة؛ راجع `AUDIT.md` قبل الاعتماد على المزامنة
- نسخ احتياطية تلقائية

الإعدادات موجودة في `js/firebase-config.js`. احتفظ بنسخة احتياطية قبل الاستيراد أو تبديل الحساب.

## 🛠️ التطوير

### تصميم الديسكتوب

للشاشات بعرض 980px فأكثر، يوجد تصميم مستقل في `css/desktop.css`: قائمة جانبية ثابتة، خلفية كحلية وألوان أزرق نيون مع إضاءة للحدود والأزرار، اختصارات لإضافة القبض والمصروف، وصفوف عمليات أوسع. أزيل تصميم الديسكتوب القديم من `styles.css`؛ إعدادات الموبايل الأساسية باقية. يدعم التنقل بالكيبورد، وتظهر الحسابات وجدول العمل مباشرة في القائمة الجانبية.

### 💳 حساباتي وكروتي

من الرئيسية أو «المزيد»، افتح **حساباتي وكروتي**:

- أضف اسم الكارت والبنك، واختر Visa أو Mastercard أو ميزة أو كاش أو محفظة.
- يظهر شعار نوع الكارت تلقائيًا، ويمكن رفع صورة لوجو البنك (PNG/JPG/WebP حتى 2 ميجا؛ تُصغَّر قبل الحفظ).
- أدخل رصيد البداية بالجنيه المصري وآخر 4 أرقام اختياريًا. لا يوجد حقل للرقم الكامل أو CVV أو الرقم السري.
- لو كارتان لنفس الحساب، اربط الثاني بالحساب الموجود؛ سيعرضان نفس الرصيد ويُحسب مرة واحدة.
- سجّل الإيداع والسحب أو التحويل بين الحسابات. التحويل لا يغيّر الإجمالي، والسحب يتطلب رصيدًا كافيًا.
- هذه أرصدة تُدخل يدويًا، وليست اتصالًا بالبنك. سجل الحسابات مستقل عن ميزانية الرئيسية وتقارير القبض والمصاريف القديمة، ويوضح ذلك داخل الصفحة لمنع جمع نفس الأموال مرتين.
- تدخل الحسابات والكروت والحركات ضمن النسخ الاحتياطية والمزامنة القائمة. الحركات بمعرفات مستقلة والمبالغ بالقروش الصحيحة؛ الدمج يحتفظ بالحركات المختلفة. إذا تجاوز سحب متزامن من جهازين الرصيد، يظهر تحذير بالرصيد السالب بعد الدمج. تظل قيود عزل المستخدمين والمزامنة العامة الواردة في `AUDIT.md` قائمة.

```bash
# تشغيل سيرفر محلي
npm start
# افتح http://127.0.0.1:8899 (يتطلب Node.js، بدون تثبيت حزم)

# اختبارات حماية البيانات والمزامنة
npm test
```

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة + المودالات |
| `app.js` | منطق التطبيق كله |
